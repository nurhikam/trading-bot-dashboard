How it works

A local runner fetches closed candles, simulates fills, and pushes one JSON file to GitHub every minute. The site reads that file directly, so numbers update without a redeploy.

Collect

Closed 1H candles from Binance mainnet. The forming candle is always dropped before any indicator runs.

Simulate

Every fill pays 0.10% fee plus 0.05% adverse slippage. Wallets are all-in long or flat, one per strategy per coin.

Publish

Equity curves, trades, drawdowns, and win rates land in data.json. The dashboard renders it client-side.

The seven

Supertrend

ATR-based trailing stop. Long while price holds above the band, flat when it breaks.

SMA cross

Fast average over slow average enters; the reverse exits. Whipsaw-prone by design, useful in choppy tape.

SMA trend

Cross filtered by a 200-bar trend line. Trades less, sits out downtrends entirely.

Trend 200

Long above the 200 average, flat below. The simplest regime filter there is.

Donchian

Buy new highs over a lookback window, exit on lows. Classic breakout mechanics.

BB squeeze

Bollinger bandwidth compression followed by expansion. Enters when volatility wakes up.

RSI revert

Fades oversold extremes and exits into strength. Few trades, fee-light, knife-catching risk included.
